Privacy Policy

Claude Workspace MCP is a personal-use OAuth client for a Google Workspace MCP server that runs locally on its owner's computer.

  • No data is collected, stored or shared with third parties by the operator of this application.
  • OAuth tokens are stored only on the user's own computer.
  • Google user data is accessed only to perform the requests the user initiates, and is not used for any other purpose.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

To revoke access at any time, visit myaccount.google.com/permissions.
